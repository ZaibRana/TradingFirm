# Spec — Part 2.5: Dossier live check

Status: **approved 2026-09-09** in chat ("straight into 2.5"), scope fixed by the plan row.

## Spec

`tests/dossier_live.py` is a manual script — never CI, never collected by pytest — that builds the app's real state (prod pool, prod Redis, prod clients, from the same settings `lifespan` reads), wraps each client method with a timer, and drives `main.get_dossier` in-process for one ticker: it prints every upstream call with its own wall clock, every section's status and what it carries, the budget the endpoint reports, and then a second request that must come back `cached: true` with zero upstream calls. It must never run against more than the one ticker named on the command line, never print a key or a URL, and never be run from CI. Acceptance: one run against prod prints the table above, its three assertions hold (`cached` on the second request, an empty `bySource` on it, and a first-request `upstreamCalls` equal to the number of calls actually timed), and a plain `curl` against the running container shows the same budget block.

## Run

```bash
docker compose run --rm --no-deps -v ./services/data-engine:/app \
    data-engine python tests/dossier_live.py AAPL
```

The 2.2/2.3 pattern: prod image, throwaway container, source mounted, prod container untouched.

## Result — run 2026-09-09 (first run, before the budget fix)

10 upstream calls for one cold AAPL dossier: 5 Finnhub, 2 EDGAR, 3 yfinance (2 downloads + 1 `Ticker`), no Alpha Vantage (yfinance answered). 9.73 s wall clock, 16.26 s of call time overlapped; slowest source Finnhub `/stock/profile2` at 4.18 s, EDGAR the fastest at 0.48 s + 0.20 s — nothing near the 8 s per-source bound. Every section `ok` except `news`, `truncated` at the 30-headline cap out of 245 stored. `bars` came back `ok` with `refreshed: true`.

**What the run found** (both fixed under `docs/specs/2.4.md`, "Correction made after 2.5"): the budget reported 14 upstream calls for 10, and a cached hit replayed the build's budget. The script now asserts both.
