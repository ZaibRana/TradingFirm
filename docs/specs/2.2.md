# Spec — Part 2.2: EDGAR filings fetcher

Status: **approved 2026-09-09** with corrections (chat review after a first build without a posted spec; see `docs/decisions.md` 2026-09-09 "G1 reworded"). This file is the corrected spec, committed with the feat commit.

## Spec

`recent_filings(ticker, forms=('8-K','4'), days=30)` returns the ticker's recent SEC filings from the EDGAR submissions feed via a ticker-to-CIK map, and `sync_filings()` stores them in `data_engine.filings`. It must never send a request without the declared User-Agent, never exceed the SEC's 10 requests per second, never retry a 403/429, and never call EDGAR from a test. Acceptance: two live calls for one ticker return 200 with the documented shape, every failure-branch row below has a passing test, and the prod container and prod database are untouched.

## Decisions the plan row leaves open (as approved)

1. Two modules, `edgar_client.py` (HTTP, User-Agent, limiter, typed errors) and `edgar.py` (fetchers, pure parser/converters, `sync_filings()`), mirroring 2.1.
2. Shared with 2.1 via a preceding `refactor:` commit: `providers/context/ratelimit.py` (`RateLimiter`), `cache.cached_json()` (read-through; 2.2 adds a `valid` shape predicate), `tickers.validate_ticker()`.
3. **Limiter:** one mechanism, a rolling window of 10 per second, no minimum gap. Module-level instance `ratelimit.edgar_limiter`, the `EdgarClient` default, injectable for tests. One uvicorn worker assumed (Dockerfile CMD has no `--workers`) — deferred note. The Finnhub limiter is still per-client — deferred, not touched here.
4. 403 and 429 both raise `EdgarRateLimited` (SEC uses 403 for undeclared clients and for throttling); 404 raises `EdgarNotFound` at the client.
5. Whole CIK map cached under one key for 24 h; an empty map raises and is never cached.
6. Per-ticker cache: the parsed rows of `filings.recent` with `filingDate` inside `today − 90` (the `days` maximum), every form, plus the oldest `filingDate` in the whole block. Bounded by date, not count. `forms` / `days` (1..90) filter in-process.
7. **Truncation:** real only when the oldest row of the whole `recent` block, before form filtering, is newer than `today − days`. Warn then, never otherwise. `recent_filings` returns `(rows, truncated)`; `sync_filings` stores `rows` and reports `truncated`; 2.4 surfaces it in `dataQuality`.
8. Amendments fold into their base form (`8-K/A` matches `'8-K'`); the row keeps the literal form.
9. **Dates:** `filed_on DATE NOT NULL` from the official `filingDate` (what `days` filters on and what 2.3/2.4 join daily bars on); `accepted_at TIMESTAMPTZ` nullable from `acceptanceDateTime` (UTC, verified live), never fabricated. Neither stays in `meta`.
10. URL is the primary document under `Archives/edgar/data/{cik}/{accession-no-dashes}/`, falling back to `{accession}-index.htm` when no document is named.
11. **Tickers:** letters-only through `validate_ticker` on the lookup side; map keys pass through `normalize_ticker` so `BRK-B` is a key but unreachable. Class shares are unreachable through both context fetchers — deferred with its own future `refactor:` (one canonical form in `validate_ticker`, hyphen/dot mapped per provider).
12. Primary key `(ticker, accession)`; the same accession appears under GOOG and GOOGL.
13. **Conflicts:** `ON CONFLICT DO NOTHING`. A filed accession never changes; a future derivation change is a one-off backfill with its own decisions entry.
14. Not in the map, or CIK known but submissions 404: open, `([], False)`, logged at warning. Both mean the SEC has nothing for the ticker; 2.4 keeps the section. The client still raises `EdgarNotFound`; `recent_filings` catches it and caches the empty block for the 15-min TTL.
15. A cached body of the wrong JSON shape is a miss (refetch, overwrite).
16. **Unequal `recent` columns: closed.** A short array can mean a shifted middle; every row after the shift would pair the wrong accession with the wrong form. `EdgarError`, nothing cached. A column absent altogether reads as all-None. Missing values inside an aligned row: drop and log.
17. Compose: `EDGAR_USER_AGENT` reaches prod `data-engine` from `.env`; the dev twin has it hard-coded empty. `.env.example` carries a blank value with a format comment.
18. Recorder trims fixtures to five tickers and the newest 60 filings; fixtures hold response bodies only.

## Writes

| write | before / after success | state left if it fails after |
|---|---|---|
| Redis `tf:cache:edgar:cik_map`, TTL 24 h | absent or stale / full `{ticker: cik}` map | SET is the last step; a SET raise is logged, no key written |
| Redis `tf:cache:edgar:filings:{T}`, TTL 15 min | absent or stale / `{rows: [90-day parsed rows], oldest: date}` | same |
| Postgres `data_engine.filings` via `upsert_filings` | rows absent / rows present; existing `(ticker, accession)` untouched (`DO NOTHING`) | one `executemany`, no explicit transaction: earlier rows can stay written on a mid-batch raise; a rerun is a no-op for them |

## Failure branches

| branch | open / closed | test function |
|---|---|---|
| User-Agent empty | closed, before HTTP | `test_client_not_configured_raises` |
| dependency down (timeout, transport) | closed, `EdgarError` | `test_client_timeout` |
| 403 or 429 | closed, `EdgarRateLimited`, one attempt | `test_client_blocked_raises_rate_limited` (403, 429) |
| non-JSON or 5xx body | closed | `test_client_bad_json`, `test_client_server_error` |
| ticker not in SEC's map | open, `([], False)`, warning | `test_recent_filings_unknown_ticker_empty` |
| CIK known, submissions 404 | open, `([], False)`, warning, cached | `test_recent_filings_404_returns_empty` (client: `test_client_404_raises_not_found`) |
| bad ticker (`AAPL1`, empty, 6 letters, `A.B`, `BRK-B`) | closed, `ValueError`, no HTTP | `test_recent_filings_rejects_bad_ticker` |
| bad `days` (0, −1, 91, 3.5, `True`, `"30"`) or empty `forms` | closed, `ValueError`, no HTTP | `test_recent_filings_rejects_bad_days` |
| empty CIK map body | closed, raises, not cached | `test_cik_map_empty_body_raises_and_is_not_cached` |
| empty `recent` block | open, `([], False)` | `test_recent_filings_empty_recent_block` |
| rows missing accession / form / filingDate | open, dropped and logged | `test_parse_submissions_drops_incomplete_rows` |
| unequal `recent` columns | closed, `EdgarError`, not cached | `test_parse_submissions_unequal_columns_raises`, `test_recent_filings_unequal_columns_not_cached` |
| block does not reach back to `today − days` | open, `truncated=True`, warning | `test_recent_filings_window_truncated` |
| repeat call | cache hit, one HTTP per URL | `test_recent_filings_repeat_hits_cache` |
| Redis absent (`redis=None`) | open, fetched uncached | `test_recent_filings_redis_absent_uncached` |
| Redis GET raises | open, fetched uncached | `test_recent_filings_redis_get_raises_uncached` |
| Redis SET raises | open, body returned, nothing cached | `test_recent_filings_redis_set_raises` |
| cached CIK map unparseable or wrong shape | open, refetched, overwritten | `test_recent_filings_corrupt_cik_map_refetches` |
| cached filings wrong shape | open, refetched, overwritten | `test_recent_filings_corrupt_filings_cache_refetches` |
| blocked mid-sync | closed, no DB write | `test_sync_filings_stops_on_block` |
| no db pool | open, fetched and not stored | `test_sync_filings_skipped_without_pool` |
| DB raise | closed, propagates | `test_upsert_filings_raise_propagates` |
| incomplete rows at the store | open, dropped | `test_upsert_filings_drops_incomplete` |
